WHAT THIS WORKSPACE DOES

A visible trail, from claim to counterclaim.

01

Commit the context

A precise claim, named references and exact excerpts are frozen with a SHA-256 snapshot.

02

Compare the text

Validators independently classify each excerpt as supporting, contradicting or insufficient. Decision fields must agree.

03

Keep the branches

Anyone can add evidence from a resolved round. Each branch has its own author, snapshot and final result.

Read results in scope. “Support only” describes supplied text, not objective truth. References and excerpts are supplied by contributors; this app does not fetch or authenticate their sources. Source counts are not votes. The seeded workshop example is synthetic test data, not real event information.
